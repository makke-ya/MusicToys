# 要件定義書: 005_melody_memory (メロディーおぼえよう！)

## 1. ゲーム概要
*   **タイトル**: メロディーおぼえよう！ (Melody Memory)
*   **コンセプト**: 有名な童謡や名曲のメロディ（およびそのちょい変えアレンジ）をお手本として聴き、同じ順番で音階パッドをタップして再現する「メロディ記憶＆耳コピ（相対音感）」トレーニングゲーム。
*   **ターゲット**: 2歳〜大人（序盤は光るパッドを目で追って弾ける設計、後半は光ヒントなしの本格耳コピ）。
*   **目的**: 聴覚ワーキングメモリ（音の並びの記憶）、音階感覚、相対音感（耳コピ力）を楽しく養う。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に、以下の3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: ここからはじめる（かんたん / 3〜5音パッド・全音ひかりガイド）
    - **レベル 15**: なれてきたら（ふつう / 5〜8音パッド・一部耳コピ）
    - **レベル 30**: ちょうせん！（むずかしい / 8音パッド・最初の1音だけ光る本格耳コピ）
2.  **レベル開始前（出題ポップアップ）**:
    - 各問題の開始前に、ポップアップで以下の情報を表示する。
        - レベル番号
        - 出題曲のヒント（例: 「🌷 チューリップ（ほんもの！）」または「🌷 チューリップ（アレンジ♪）」）
        - 音の数（例: 「3おんの メロディー！」）
        - ガイドモード表示（例: 「🌟 ぜんぶ ひかるよ」 / 「👂 さいしょの1おんだけ ひかるよ！」）
3.  **お手本再生（入力ロック）**:
    - ポップアップが消えると同時に、お手本メロディが自動再生される。
    - **お手本再生中は音階パッド全体をグレーアウト表示にし、ユーザーのタップ入力を無効化する。**
    - レベルの `guideMode` に応じて、お手本再生中に対応する音階パッドが光り、動物キャラクターがジャンプする：
        - `"all"`（Lv.1〜20）：すべての音が光る。
        - `"partial"`（Lv.21〜30）：前半の音だけ光り、後半の音は光らず「❓」表示で音だけ鳴る。
        - `"first_only"`（Lv.31〜50）：最初の1音目（基準音）だけ光り、2音目以降は光らず音だけ鳴る（相対音感・耳コピ）。
4.  **まねっこ入力（入力解除）**:
    - お手本再生が終わると、「🎹 おなじ じゅんばんで タッチしてね！」の合図が表示され、グレーアウトが解除されて入力可能になる。
    - プレイヤーが音階パッドをタップすると、その音階の音が鳴り、画面上部の「音符スロット（🎵）」が順番に埋まっていく。
5.  **判定**:
    - 必要な音数だけタップし終えると、自動的に入力がロックされ、各音の正誤判定とスコア・星（⭐1〜3）の算出が行われる。
6.  **結果表示（判定ポップアップ）**:
    - **🌟 パーフェクト（⭐⭐⭐）**: 全音正解！
    - **😊 グッド（⭐⭐）**: 半数以上の音が正解！
    - **💪 がんばろう（⭐）**: 正解が半数未満。
    - 今回のモチーフ曲名（例：「🐸 かえるのうた（ちょい変えアレンジ）」）と正解の音階名（例：「ド → レ → ミ → ド」）を表示する。
    - 星2つ以上で「つぎへ！ ➡️」ボタンが表示され次のレベルへ進める。星1つの場合は「🔄 もういちど」でリトライ可能。

### 2.3. 有名曲モチーフと「ちょい変えランダムアレンジ」
各レベルには、誰もが知っている童謡・民謡・クラシック名曲のフレーズと、その「ちょい変えアレンジ（末尾音の変更、折り返し変更、開始音シフト等）」を複数登録する。
さらにロジック層でも動的アレンジ生成関数 (`createMelodyVariation`) を備え、同じレベルを何度遊んでも直前と同じ問題にならず、曲名での決め打ちを防いで「耳で聴く力」を養う。

## 3. 判定・スコアリング

### 3.1. 音の正誤判定
お手本の音階配列 `expectedNotes` とプレイヤーが入力した音階配列 `actualNotes` を1音ずつ比較する。
- 一致（`expectedNotes[i] === actualNotes[i]`）：`correct`（100点）
- 不一致：`wrong`（0点）

### 3.2. スコア計算
- 正解音数 × 100点
- 全問正解（パーフェクト）ボーナス：+100点
- レベルボーナス：レベル番号 × 10点

### 3.3. 星判定
- ⭐⭐⭐（パーフェクト）：全音正解（`correctCount === totalNotes`）
- ⭐⭐（グッド）：半数以上正解（`correctCount >= Math.ceil(totalNotes / 2)`）
- ⭐（がんばろう）：正解が半数未満
