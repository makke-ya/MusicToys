# 要件定義書: 007_melody_detective (まちがいさがし・おんがくたんてい！)

## 1. ゲーム概要
*   **タイトル**: まちがいさがし・おんがくたんてい！ (Melody Detective)
*   **コンセプト**: 「🦉 おてほん先生」が演奏したメロディーと、「🐶 まねっこ生徒」が演奏したメロディーの2つを聴き比べ、「同じか違うか（⭕❌）」や「何番目の音を間違えたか（1ばんめ〜Nばんめ）」を見抜く**聴覚比較・音楽間違い探しゲーム**。
*   **ターゲット**: 1歳〜6歳のお子様から大人まで（序盤は「おなじ⭕ / ちがう❌」の直感2択、中盤以降は間違えた音符キャラを指さしタッチする探偵モード）。
*   **目的**: 聴覚的注意力（2つのフレーズの比較リスニング）、聴覚ワーキングメモリ、微細な音程差の識別力を楽しく養う。
*   **既存ゲームとの差別化**:
    *   `004_rhythm_tap` のような「タイミングよくボタンを連打する操作」や、`005_melody_memory` のような「鍵盤の並びを覚えて自分で弾く操作」を一切必要としない。
    *   鍵盤演奏がまだ難しい幼児でも、「あれ？まねっこ生徒が変な音を鳴らしたぞ！」と耳で聴き比べて指さしタッチするだけで探偵気分を楽しめる。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: かんたん（Lv.1〜15 / 「おなじ⭕・ちがう❌」の2択クイズ）
    - **レベル 15**: ふつう（Lv.16〜30 / 「なんばんめの おとが ちがう？」3〜5音の音符キャラ探し）
    - **レベル 30**: むずかしい（Lv.31〜50 / 6〜7音・微細な音程差＆ランダムキー移調の名探偵モード）
2.  **レベル開始前（出題ポップアップ）**:
    - レベル番号、出題曲モチーフ（例: 「🌷 チューリップ」）、音の数（例: 「4おんの メロディー」）、調査モード（「⭕❌ おなじ？ちがう？」または「🔍 なんばんめが ちがう？」）を表示。
3.  **お手本＆まねっこ連続再生（入力ロック・グレーアウト）**:
    - ポップアップ終了後、まず **「① 🦉 おてほん先生」** のメロディーが再生され、短い間のあとに **「② 🐶 まねっこ生徒」** のメロディーが再生される。
    - 再生中、画面中央の音符キャラ（1ばんめ〜Nばんめ）が順番にハイライトされ、今何番目の音が鳴っているかが視覚的にわかる。
    - **お手本およびまねっこ再生中は、回答ボタン（⭕❌ボタン・音符キャラ選択ボタン）をすべてグレーアウト表示（`.choice-disabled` + `disabled = true`）にし、ユーザーのタップ入力を完全に無効化する。**
4.  **推理・回答入力（ロック解除）**:
    - 2つのメロディーの再生が終わると、「🔍 どっちかな？ タッチしてね！」（または「🔍 まちがえた おんぷを タッチしてね！」）の合図が出て、グレーアウトが解除される。
    - **Lv.1〜15 (`same_or_diff` モード)**: 画面下部の大きな「⭕ ぴったり おなじ！」「❌ ちがう おとが ある！」の2択ボタンから選ぶ。
    - **Lv.16〜50 (`find_index` モード)**: 並んだ音符キャラボタン（1ばんめ〜Nばんめ）の中から、まねっこ生徒が間違えた番号の音符キャラをタップして選ぶ。
5.  **判定・結果表示（答え合わせポップアップ）**:
    - 回答すると自動判定され、星（⭐1〜3）とスコア、そして**「おてほん：ド → レ → ミ」「まねっこ：ド → レ → ソ（3ばんめが ちがう！）」**の分かりやすい比較解説を表示する。
    - 星2つ以上で「つぎへ！ ➡️」ボタンが表示され次のレベルへ進める。星1つの場合は「🔄 もういちど」でリトライ可能。

### 2.2. 全50レベルの難易度進行 (`level_design.json`)

| レベル帯 | モード | 音数 | 間違いの聴き分け難易度 (`mistakeDistance`) | 特徴 |
|:---:|:---:|:---:|:---:|---|
| **Lv.1〜5** | `same_or_diff` (⭕❌2択) | 3音 | `large`（3度〜5度の大きな音程差） | 1〜2歳児でも「おなじ！」「ちがう！」がすぐわかる入門編 |
| **Lv.6〜10** | `same_or_diff` (⭕❌2択) | 4音 | `large`（大きな音程差） | 4音の有名童謡フレーズでおなじ・ちがいを聴き比べ |
| **Lv.11〜15** | `same_or_diff` (⭕❌2択) | 4〜5音 | `medium`（2度〜3度の音程差） | 少しさりげない間違いを見抜く⭕❌クイズ総仕上げ |
| **Lv.16〜22** | `find_index` (何番目？) | 3〜4音 | `large`（大きな音程差） | 探偵モード開始！3〜4個の音符キャラから間違えた番号を特定 |
| **Lv.23〜30** | `find_index` (何番目？) | 5音 | `medium`（2度〜3度の音程差） | 5音のメロディーの途中（2〜4番目など）の間違いも特定 |
| **Lv.31〜40** | `find_index` (何番目？) | 6音 | `medium`〜`subtle` + ランダムキー移調 | 毎回キー（基準音）がシフトし、6音から微細な違いを探す |
| **Lv.41〜50** | `find_index` (何番目？) | 7音 | `subtle`（隣り合う音・半音差）+ 移調 | 7音の長尺フレーズ×隣音の微細変化×高速再生の名探偵試練 |

### 2.3. 毎回問題が変化する仕組み（決め打ち防止）
*   各レベルに5種類以上の童謡・名曲モチーフを登録し、直前と同じメロディーが連続しないよう制御。
*   **動的ミステリー生成 (`generateProblem`)**:
    - `same_or_diff` モードでは、毎回ランダムに「おなじ（`isDifferent: false`）」か「ちがう（`isDifferent: true`）」かを決定（同じ正解が3回以上偏らない制御付き）。「ちがう」場合は間違える音の位置（`mistakeIndex`）と変化後の音高も毎回ランダムに生成される。
    - `find_index` モードでは、毎回ランダムな位置（`0` 〜 `noteCount - 1`、直前の問題と異なる位置を優先）の1音を、`mistakeDistance` に応じた別の音高に動的変換する。
    - さらに高レベル（Lv.31〜50）では出題ごとに基準ピッチ（`transposeSemitones`: `-3` 〜 `+4` 半音）もランダムに変化するため、同じレベルを何度遊んでも毎回新しい問題になる。

## 3. 判定・スコアリング

### 3.1. 正誤判定と星評価
*   **⭐⭐⭐（パーフェクト・名探偵！）**:
    - 正解（`same_or_diff` で正答、または `find_index` で間違えた音の位置 `mistakeIndex` をピタリと的中）。
    - スコア: `300点 + パーフェクトボーナス100点 + (レベル × 10点)`（例: Lv.1 = 410点）。
    - `canAdvance: true`
*   **⭐⭐（グッド・おしい推理！）**:
    - `find_index` モードで、間違えた音の**すぐ隣の位置**（`Math.abs(userChoice - mistakeIndex) === 1`）を選んだ場合（「おしい！すぐとなりの音だったね！」）。
    - スコア: `150点 + (レベル × 10点)`。
    - `canAdvance: true`
*   **⭐（がんばろう！）**:
    - それ以外の不正解。
    - スコア: `レベル × 10点`（参加ボーナス）。
    - `canAdvance: false`
