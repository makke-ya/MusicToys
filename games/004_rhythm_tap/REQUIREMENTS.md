# 要件定義書: 004_rhythm_tap (リズムにのろう！)

## 1. ゲーム概要
*   **タイトル**: リズムにのろう！ (Rhythm Tap)
*   **コンセプト**: お手本のリズムパターンを聴いて、同じリズムを画面タップで再現する、直感的なリズムトレーニングゲーム。
*   **ターゲット**: 2歳〜大人（特に2〜3歳児が画面をポンポン叩くだけでも楽しめる設計）。
*   **目的**: リズム感覚、拍子感覚、タイミングの正確さを養う。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に、以下の3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: ここからはじめる（かんたん）
    - **レベル 15**: なれてきたら（ふつう）
    - **レベル 30**: ちょうせん！（むずかしい）
2.  **レベル開始前（出題ポップアップ）**: 
    - 各問題の開始前に、ポップアップで以下の情報を表示する。
        - レベル番号
        - リズムの拍数（例: 「4かいの リズム！」）
        - テンポ表示（例: 「はやさ: ゆっくり 🐢」）
    - ポップアップにはワクワク感を演出するアニメーションを付与する。
3.  **お手本再生**: ポップアップが消えると同時に、お手本のリズムパターンが再生される。
    - 再生中は太鼓のキャラクターがリズムに合わせてアニメーションする（視覚フィードバック）。
    - お手本再生中は、画面下部に拍のタイミングを示すガイドドット（●）が順番に光る。
    - **お手本再生中は太鼓エリアをグレーアウト表示にし、ユーザーのタップ入力を受け付けない（入力不可状態）とする。**
4.  **タップ入力**: お手本再生後、「たたいてね！」のガイドが表示され、太鼓エリアのグレーアウトが解除されて入力可能になり、子どもが画面をタップしてリズムを再現する。
    - タップ領域は画面の大部分を占める大きなエリア（太鼓の絵）。
    - タップするたびに打楽器音が鳴り、視覚エフェクト（波紋など）が表示される。
5.  **判定**: すべてのタップが完了（必要拍数に達した）後、自動的に判定が行われる。
    - 各タップのタイミング精度を個別に評価し、総合スコアを算出する。
6.  **結果表示（判定ポップアップ）**:
    - **🌟 パーフェクト**: 全タップが許容範囲内 → 星3つ + 大きなアニメーション
    - **😊 グッド**: 半数以上が許容範囲内 → 星2つ
    - **💪 がんばろう**: 半数未満 → 星1つ + 励ましメッセージ
    - 「もういちど」「つぎへ！」ボタンを表示。
7.  **進行**: 星2つ以上で次のレベルに進める。星1つの場合は同じレベルをリトライ。

### 2.2. レベルデザイン（難易度調整）

レベルの具体的なパラメータは外部のJSONファイル (`level_design.json`) で管理する。

#### パラメータ一覧

| パラメータ | 説明 | レベルに応じた変化 |
|-----------|------|------------------|
| **拍数 (beatCount)** | 1問あたりのリズムの拍数 | 2拍 → 4拍 → 6拍 → 8拍 |
| **テンポ (bpm)** | 1分あたりの拍数 | 60 → 80 → 100 → 120 BPM |
| **音符パターン (pattern)** | リズムの構成 | 4分音符のみ → 8分音符混在 → 付点・休符あり |
| **判定許容範囲 (toleranceMs)** | タップのズレ許容時間 | 300ms → 200ms → 150ms → 100ms |
| **音色 (sound)** | タップ時に鳴る打楽器音 | 太鼓 → さまざまな打楽器 |
| **お手本再生回数 (demoCount)** | お手本の再生回数 | 2回 → 1回 |
| **視覚ガイド (visualGuide)** | タイミングガイドの有無 | あり → 小さくなる → なし |

#### レベル帯ごとの設計方針

*   **Lv.1〜5（2歳〜）**: かんたんリズム
    - 2〜3拍の等間隔パターン（タンタン、タンタンタン）
    - テンポ: 60〜70 BPM（ゆっくり）
    - 許容範囲: 300ms（かなり寛大）
    - お手本: 2回再生 + 大きな視覚ガイド
    - 音色: 太鼓（ドン！）
    - 2歳児が適当にポンポン叩いても「グッド」が出やすい設計

*   **Lv.6〜10（3歳〜）**: リズムにのろう
    - 4拍のパターン、等間隔＋簡単な変化（タンタンタンウン）
    - テンポ: 70〜90 BPM
    - 許容範囲: 200ms
    - お手本: 2回再生 + 視覚ガイド（小さめ）
    - 音色: 太鼓、カスタネット

*   **Lv.11〜15（4歳〜）**: リズムマスター
    - 4〜6拍、8分音符を含むパターン（タタタンタン）
    - テンポ: 80〜100 BPM
    - 許容範囲: 150ms
    - お手本: 1回再生 + 視覚ガイド（最小）
    - 音色: 様々な打楽器

*   **Lv.16〜20（5歳〜）**: リズムチャンピオン
    - 6〜8拍、付点リズム・シンコペーションを含む
    - テンポ: 100〜120 BPM
    - 許容範囲: 100ms
    - お手本: 1回再生、視覚ガイドなし
    - 音色: ランダム

### 2.3. リズムパターンの表現方法

パターンは配列で表現する。各要素は拍の開始からの相対時間（ビート単位）。

```json
{
  "level": 1,
  "bpm": 60,
  "pattern": [0, 1],
  "toleranceMs": 300,
  "sound": "taiko",
  "demoCount": 2,
  "visualGuide": true
}
```

パターン例:
- `[0, 1]` → タン タン（2拍、等間隔）
- `[0, 1, 2, 3]` → タン タン タン タン（4拍、等間隔）
- `[0, 0.5, 1, 2]` → タタ タン タン（8分+8分+4分+4分）
- `[0, 1, 1.5, 2, 3]` → タン タタ タン タン（4分+8分+8分+4分+4分）
- `[0, 0.75, 1, 2, 2.5, 3]` → 付点リズムを含む複雑なパターン

### 2.4. 2歳児向けUX（ユーザー体験）
*   **大きなタップエリア**: 画面中央に大きな太鼓イラスト。どこを触ってもタップとして受け付ける。
*   **常にフィードバック**: 
    - お手本再生中でも画面をタップすれば音が鳴る（練習モードとして機能）。
    - タップするたびに太鼓が揺れ、波紋エフェクトが表示される。
*   **ペナルティなし**: 星1つでもゲームオーバーにならない。何度でもリトライ可能。
*   **「もういちど きく」ボタン**: いつでもお手本を再生し直せる。

## 3. 判定・スコアリング

### 3.1. タイミング判定
各タップについて、お手本の対応するタイミングとのズレ（ms）を計測する。

- **パーフェクト判定**: ズレ ≤ toleranceMs × 0.5
- **グッド判定**: ズレ ≤ toleranceMs
- **ミス判定**: ズレ > toleranceMs

### 3.2. スコア計算
- パーフェクト: 100点/タップ
- グッド: 50点/タップ
- ミス: 0点/タップ
- **レベルボーナス**: レベル番号 × 10点 を加算

### 3.3. 星判定
- ⭐⭐⭐ (パーフェクト): 全タップがグッド以上、かつ半数以上がパーフェクト
- ⭐⭐ (グッド): 半数以上のタップがグッド以上
- ⭐ (がんばろう): それ以外

## 4. 画面構成

### 4.1. スタート画面
- ゲームタイトル「🥁 リズムにのろう！」
- レベル選択ボタン × 3
- 楽器（音色）選択（ラジオボタン）
- 「あそびかた」ボタン

### 4.2. プレイ画面
- **上部**: レベル表示、スコア
- **中央**: 太鼓エリア（大きなタップ領域）
    - 太鼓のイラスト（タップで振動アニメーション）
    - 波紋エフェクト表示レイヤー
- **下部**: ガイドドット列（リズムの視覚ガイド）
- **ボタン**: 「🔊 もういちど きく」（お手本リプレイ）

### 4.3. 結果画面
- 星表示（⭐1〜3）
- スコア
- リーダーボード（ランキング）表示
- 「もういちど」「つぎへ！」ボタン

## 5. 技術要件

### 5.1. 音声
- **Web Audio API** を使用。低遅延でのタップ音再生が必須。
- **打楽器音源**: 新規に追加が必要。以下の音源ファイルを `static/sounds/percussion/` に配置する。
    - `taiko.mp3` — 太鼓
    - `castanet.mp3` — カスタネット
    - `tambourine.mp3` — タンバリン
    - `woodblock.mp3` — ウッドブロック
    - `cymbal.mp3` — シンバル
- **お手本再生**: AudioContextのスケジューリング機能で正確なタイミング再生。
- **タイミング計測**: `performance.now()` を使用し、高精度でタップタイミングを記録。

### 5.2. UI/UX
- **TailwindCSS** + ゲーム固有CSSでスタイリング。
- **アニメーション**: CSS Animations + requestAnimationFrame
    - 太鼓の振動（タップ時）
    - 波紋エフェクト（タップ時）
    - ガイドドットの点灯（お手本再生時）
    - 星の出現アニメーション（結果表示時）
- **ui-lock.js** を適用（拡大縮小禁止、マルチタッチ無効）。

### 5.3. データ保存
- `localStorage` に最高スコア、クリア済みレベル、選択音色を保存。
- AWS APIへのスコア送信（既存の `ScoreManager` を利用）。
