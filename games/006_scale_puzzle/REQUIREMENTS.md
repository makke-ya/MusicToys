# 要件定義書: 006_scale_puzzle (おとのかいだん・パズル！)

## 1. ゲーム概要
*   **タイトル**: おとのかいだん・パズル！ (Scale Puzzle)
*   **コンセプト**: 音の高さ（ピッチ・音階構造）をじっくり聴き比べ、階段の抜けた穴（虫食い `[？]`）に正しい高さの音ブロックをはめ込んだり、バラバラになった音ブロックを「低い順（のぼり階段）」「高い順（くだり階段）」に並べ替えて動物の橋渡しをする**空間・音階ロジックパズルゲーム**。
*   **ターゲット**: 1歳〜大人（序盤は大きさ・色ヒントつきの1箇所穴埋めパズル、後半は視覚ヒントなし＆ランダム移調での本格ピッチソートパズル）。
*   **目的**: 時間に追われるタイミング操作を排除し、自分のペースで音を鳴らして聴き比べることで、相対音感・音階構造（順次進行・跳躍進行）・ピッチ比較力を楽しく養う。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に、以下の3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: ここからはじめる（かんたん / 虫食い1〜2個の穴埋めパズル・サイズヒントあり）
    - **レベル 15**: なれてきたら（ふつう / 虫食い2〜3個 ＆ 3〜4音の並び替えパズル）
    - **レベル 30**: ちょうせん！（むずかしい / ヒントなし！4〜6音の本格ソートパズル＆ランダム移調）
2.  **レベル開始前（出題ポップアップ）**:
    - 各問題の開始前に、ポップアップで以下の情報を表示する。
        - レベル番号
        - パズルのお題（例: 「🪜 のぼりかいだん（ド→レ→ミ）」「❓ あなうめパズル（1こ）」「🔀 ひくいじゅんに ならべよう！」）
        - 階段の段数とヒントモード表示
3.  **お手本再生（入力ロック）**:
    - ポップアップが消えると同時に、完成形の階段メロディがお手本として再生される。
    - **お手本再生中は候補ブロックおよび試聴ボタン全体をグレーアウト表示（`.block-disabled` + `disabled`属性）にし、ユーザーの入力を完全に無効化する。**
    - お手本再生中、階段のステップが順番に光り、動物キャラクターがゴールを目指してステップを確認する。
4.  **試聴＆パズル組み立て（入力解除）**:
    - お手本再生が終わると、「🧩 ブロックを ききくらべて はめよう！」の合図が表示され、グレーアウトが解除されて操作可能になる。
    - 画面下部には候補となる「おとブロック」が並ぶ。
        - **🔊 きく（試聴ボタン）**: ブロックをスロットに入れずに、何度でもそのブロックの音だけを鳴らして聴き比べができる。
        - **ブロック本体タップ（配置）**: そのブロックの音を鳴らしつつ、階段の次の空欄 `[？]` スロットにブロックをはめ込む（1つ戻すボタンでやり直しも可能）。
5.  **完成＆階段わたりの答え合わせ演出**:
    - すべての空欄 `[？]` にブロックが埋まると入力がロックされ、動物キャラクターが1段ずつ音を鳴らしながら階段を歩いて渡る！
    - 各ステップの正誤判定とスコア・星（⭐1〜3）が算出される。
6.  **結果表示（判定ポップアップ）**:
    - **🌟 パーフェクト（⭐⭐⭐）**: 全ての段が正解！動物がゴールに到着！
    - **😊 グッド（⭐⭐）**: 半数以上の段が正解！
    - **💪 がんばろう（⭐）**: 正解が半数未満。
    - 正解の音階並び（例：「ド → レ → ミ → ファ → ソ」）を表示し、星2つ以上で「つぎへ！ ➡️」ボタンで次レベルへ進める。

### 2.2. パズルモードと全50レベルの難易度進行

| レベル帯 | パズルモード (`puzzleMode`) | 内容・特徴 | 視覚ヒント (`hintMode`) |
|---------|---------------------------|-----------|------------------------|
| **Lv.1〜10** | `fill_blank` (虫食い1個) | 3〜5段の階段で1箇所だけ `[？]` が空欄。候補ブロック2〜3個から選ぶ。 | `full` (色・高さバー表示) |
| **Lv.11〜20** | `fill_blank` (虫食い2〜3個) | 4〜6段の階段（のぼり・くだり・スキップ階段）で2〜3箇所が空欄。候補3〜5個。 | `partial` (高さヒント控えめ) |
| **Lv.21〜30** | `sort_asc` / `sort_desc` (3〜4音ソート) | 全ての段が空欄 `[？]`。バラバラの3〜4個のブロックを低い順（または高い順）に並べ替える。 | `partial` → `none` |
| **Lv.31〜40** | `sort_asc` / `sort_desc` (4〜5音ソート) | 視覚ヒントなし（全候補ブロックが同じ見た目 `?`）。耳での試聴比較だけで4〜5音をソート。毎回ランダム移調あり。 | `none` (耳だけで比較) |
| **Lv.41〜50** | `sort_asc` / `sort_desc` (5〜6音ソート) | 5〜6音の本格的な音階・分散和音・ペンタトニックソート。ランダム移調（0〜6半音）＋全音/半音インターバルの精密聴き分け。 | `none` (マスター耳トレ) |

### 2.3. 毎回問題が変化する仕組み（決め打ち防止）
- 各レベルに5種類以上の音階パターン候補（`patterns`）を収録。
- 出題ごとに `generateProblem()` が以下を動的に変化させる：
  1. **直前と異なるパターンの選択**（連続重複の防止）
  2. **虫食い位置（`blankIndices`）の動的ランダム化**（同じ「ド・レ・ミ・ファ」でも毎回違う段が `[？]` になる）
  3. **ダミー候補ブロック（`distractors`）と並び順（`candidateBlocks`）のランダムシャッフル**
  4. **ランダム移調（`transposeSemitones`）**: 中〜高レベルでは基準ピッチ自体が半音単位でシフトするため、絶対音感や位置の丸暗記が通用せず、必ず耳で聴き比べる必要がある。

## 3. 判定・スコアリング
- 正解ステップ数 × 100点
- 全段正解（パーフェクト）ボーナス：+100点
- レベルボーナス：レベル番号 × 10点
- **星判定**:
  - ⭐⭐⭐（パーフェクト）：全空欄が正解
  - ⭐⭐（グッド）：半数以上の空欄が正解
  - ⭐（がんばろう）：正解が半数未満
