# 要件定義書: 009_chord_mood (わおんの きもち！おてんきハーモニー)

## 1. ゲーム概要
*   **タイトル**: わおんの きもち！ (Chord Mood / おてんきハーモニー)
*   **コンセプト**: 基準音（ルート音）が毎回ランダムに変わる中で、鳴り響く和音（または2〜3連続の和音進行）が持つ「きもち（響きのキャラクター：明るいメジャー☀️・悲しいマイナー🌧️・びっくりディミニッシュ⚡・ふしぎオーロラ🌈）」を相対的に聴き分け、対応するお天気＆どうぶつパネルをタップして空のお天気を当てる和声感トレーニングゲーム。
*   **ターゲット**: 1歳〜大人（序盤は光る太陽・雨パネルとアルペジオ補助で直感的に遊べ、中盤以降は転回形・和音進行・四和音7thの色彩聴き分けまで対応）。
*   **目的**: 相対的な和声感（長調・短調・不協和音・浮遊和音の色彩識別）、転回形に対する響きの恒常性、および和音進行（カデンツ・ストーリー）の聴き取り能力を楽しく養う。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に、以下の3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: ここからはじめる（かんたん / ☀️はれ・🌧️あめの2択・ひかりガイド＆アルペジオ補助）
    - **レベル 15**: なれてきたら（ふつう / 3〜4種類のお天気和音・転回形・2れんぞく和音進行）
    - **レベル 30**: ちょうせん！（むずかしい / 3れんぞく和音進行・四和音7thハーモニー耳コピ）
2.  **レベル開始前（出題ポップアップ）**:
    - 各問題の開始前に、ポップアップで以下の情報を表示する。
        - レベル番号
        - お天気ストーリーのヒント（例: 「🌻 ぽかぽか おひさま」「🌦️ あめあがりの にじ」）
        - 和音の数（例: 「1つの わおん！」「2れんぞくの わおん！」）
        - ガイドモード表示（例: 「🌟 こたえが ひかるよ」「👂 よく きいて あてよう！」）
3.  **お手本再生（入力ロック）**:
    - ポップアップが消えると同時に、お手本の和音（または和音進行）が自動再生される。
    - **お手本再生中はお天気パッド全体をグレーアウト表示（`.pad-disabled` かつ `disabled = true`）にし、ユーザーのタップ入力を完全に無効化する。**
    - レベルの `guideMode` に応じて、お手本再生中に対応するお天気パッドが光る：
        - `"all"`（Lv.1〜8）：すべての和音でお手本中に対応するお天気パッドが光る。
        - `"first_only"`（Lv.23〜26, Lv.31〜34）：複数和音進行の最初の1和音目だけ光り、2和音目以降は「❓」表示で耳だけで聴き取る。
        - `"none"`（Lv.9〜22, Lv.27〜30, Lv.35〜50）：光ヒントなし（純粋に和音の響きだけでお天気を当てる）。
4.  **お天気パネル入力（入力解除）**:
    - お手本再生が終わると、「☀️ どんな きもちかな？ タッチしてね！」の合図が表示され、グレーアウトが解除されて入力可能になる。
    - プレイヤーがお天気パッドをタップすると、今回の基準音（ルート音）でその種類の和音が鳴り、空の背景演出が変化し、画面上部の「お天気スロット（☁️）」が順番に埋まっていく。
5.  **判定**:
    - 必要な和音数（1〜3ステップ）だけタップし終えると、自動的に入力がロックされ、各ステップの正誤判定とスコア・星（⭐1〜3）の算出が行われる。
6.  **結果表示（判定ポップアップ）**:
    - **🌟 パーフェクト（⭐⭐⭐）**: 全ステップ正解！
    - **😊 グッド（⭐⭐）**: 半数以上のステップが正解！
    - **💪 がんばろう（⭐）**: 正解が半数未満。
    - 今回のストーリー名と正解のお天気進行（例：「🌧️ あめ → ☀️ はれ」）を表示する。
    - **判定画面内リプレイ＆聴き比べ機能**:
      - ポップアップ内の **「🔊 もういちど わおんを きく (`#judgment-replay-btn`)」** で、正解の解説を見ながら今の問題の和音（または和音進行）を何度でも聴き直せる。
      - 不正解時は **「👂 えらんだ音と ききくらべる (`#judgment-replay-actual-btn`)」** が表示され、自分が選んだ和音と正解の和音を連続再生して違いを聴き比べられる。
    - **同一問題リトライ対応 (`keepCurrentProblem = true`)**:
      - 「🔄 おなじ もんだいに ちょうせん (`#retry-level-btn`)」を押すと、別のランダムな和音に変わることなく、**同じ基準音・転回形・和音進行を維持したまま (`startLevelRound(true)`)** リトライできる。
    - 星2つ以上で「つぎへ！ ➡️」ボタンが表示され次のレベルへ進める。

### 2.2. お天気和音パッドの定義（全4種類）

| インデックス | ID | お天気名 | 響きのきもち | 構成音（三和音 / 四和音） | カラー | 動物アイコン |
|:---:|:---:|:---:|---|---|---|---|
| `0` | `major` | **☀️ はれ** | にこにこ・あかるい | 長三和音 `[0, 4, 7]` / Maj7 `[0, 4, 7, 11]` | きいろ (`#f59e0b`) | `02_yellow.png` |
| `1` | `minor` | **🌧️ あめ** | しくしく・かなしい | 短三和音 `[0, 3, 7]` / m7 `[0, 3, 7, 10]` | あお (`#0ea5e9`) | `03_blue.png` |

### 2.3. 全50レベルの難易度進行と毎回問題が変化する仕組み
- **Lv.1〜15（かんたん：☀️はれ vs 🌧️あめ の2択・単発和音）**:
  - Lv.1〜8は視覚ガイドあり（`"all"`）＋和音と軽いアルペジオ補助（`arpeggioHint: true`）で、1〜2歳児でも明るい和音＝☀️、悲しい和音＝🌧️を楽しく体験。
  - Lv.9〜15は視覚ガイドなし（`"none"`）。毎回基準音（ルートMIDI番号：57(A3)〜68(G#4)の12半音）がランダムにシフトするため、絶対音感的な高さの暗記ではなく「長三和音か短三和音か」の純粋な響きの違いで判断する。
- **Lv.16〜30（ふつう：3〜4択への拡張 ＆ 転回形・2和音進行）**:
  - Lv.16〜22は「⚡かみなり（減三和音）」「🌈オーロラ（増三和音）」が加わり3〜4択に拡大。さらに第1転回形・第2転回形もランダムに出題される。
  - Lv.23〜30は**2連続の和音進行（`stepCount: 2`）**が出題（「🌧️あめ → ☀️はれ」「⚡かみなり → ☀️はれ」など）。
- **Lv.31〜50（むずかしい：3連続和音進行カデンツ ＆ 四和音7thの色彩）**:
  - Lv.31〜40は**3連続の和音進行（`stepCount: 3`）**を聴き取って3スロットで再現。
  - Lv.41〜50は四和音（`useSeventh: true`）が加わり、ランダムな基準音・転回形・短い発音時間で3連続の和音進行を聴き分けるマスター領域。
- **毎回問題が変化する仕組み**:
  - 出題ごとに基準音（ルート音：12半音）と転回形（基本形/第1/第2）、進行パターンを動的に選択し、直前の問題と同じ進行＆同じルート音が連続しないよう制御する。また `createProgressionVariation` により動的な進行バリエーションも生成可能。

## 3. 判定・スコアリング
- 正解ステップ数 × 100点
- 全ステップ正解（パーフェクト）ボーナス：+100点
- レベルボーナス：レベル番号 × 10点
- 星判定：全問正解＝⭐⭐⭐、半数以上正解＝⭐⭐、半数未満＝⭐
