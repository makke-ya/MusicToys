# 要件定義書: 008_dynamics_beat (おおきい？ちいさい？たいこでドン！)

## 1. ゲーム概要
*   **タイトル**: おおきい？ちいさい？たいこでドン！ (Dynamics Beat)
*   **コンセプト**: お手本の「強い音（フォルテ `f`）・中くらいの音（メゾフォルテ `mf`）・弱い音（ピアノ `p`）」の並びや、「拍子のアクセント（2拍子・3拍子・4拍子・変拍子）」「クレッシェンド（だんだん強く）／デクレッシェンド（だんだん弱く）」を耳で聴き分け、大きさの異なる太鼓パッドを同じ順番で叩いて再現するダイナミクス＆拍子感トレーニングゲーム。
*   **ターゲット**: 1歳〜大人（序盤は大・小2つの太鼓と光ガイドで直感的に遊べ、後半は3段階ダイナミクス・光ヒントなしの本格拍子＆強弱聴き分け）。
*   **目的**: 音楽の表現に不可欠なダイナミクス（強弱変化）の聴き分けと、強拍・弱拍による拍子感（2拍子・3拍子・4拍子）を楽しく養う。

## 2. ゲームプレイの流れ

### 2.1. 基本フロー
1.  **レベル選択**: ゲーム開始時に、以下の3つのスタート地点から選択できる（全50レベル）。
    - **レベル 1**: ここからはじめる（かんたん / 大・小2つのたいこ・ひかりガイド）
    - **レベル 15**: なれてきたら（ふつう / 拍子アクセント＆3つのたいこ・クレッシェンド）
    - **レベル 30**: ちょうせん！（むずかしい / おとだけで聴き分ける本格ダイナミクス！）
2.  **レベル開始前（出題ポップアップ）**:
    - 各問題の開始前に、ポップアップで以下の情報を表示する。
        - レベル番号
        - 出題パターンのテーマ（例: 「💃 3びょうしの ワルツ（ドン・ト・ト）」または「📈 だんだん おおきく（クレッシェンド）！」）
        - 拍数（例: 「3かいの リズム！」）
        - ガイドモード表示（例: 「🌟 ぜんぶ ひかるよ」 / 「🎧 おとだけで ききわけよう！」）
3.  **お手本再生（グレーアウト＆入力ロック）**:
    - ポップアップが消えると同時に、お手本の強弱パターンが自動再生される。
    - **お手本再生中は太鼓パッド全体をグレーアウト表示（`pad-disabled` クラス＋`disabled = true`）にし、ユーザーのタップ入力を無効化する。**
    - レベルの `guideMode` に応じて、お手本再生中に対応する太鼓パッドが光り、動物キャラクターがジャンプする：
        - `"all"`（Lv.1〜10）：すべての拍が光る。
        - `"partial"`（Lv.11〜15）：前半の拍だけ光り、後半の拍は光らず「❓」表示で音だけ鳴る。
        - `"first_only"`（Lv.16〜25）：最初の1拍目だけ光り、2拍目以降は光らず音だけ鳴る。
        - `"none"`（Lv.26〜50）：光ガイドなし。耳だけで強弱と拍子アクセントを聴き分ける。
4.  **まねっこ入力（入力ロック解除）**:
    - お手本再生が終わると、「🥁 おなじ つよさで たたいてね！」の合図が表示され、グレーアウトが解除されて入力可能になる。
    - プレイヤーが太鼓パッド（小 `p` / 中 `mf` / 大 `f`）をタップすると、その強さの太鼓音が鳴り、画面上部の「拍スロット」に大きさの異なるアイコンが順番に埋まっていく。
5.  **判定**:
    - 必要な拍数だけタップし終えると、自動的に入力がロックされ、各拍の強弱一致判定とスコア・星（⭐1〜3）の算出が行われる。
6.  **結果表示（判定ポップアップ）**:
    - **🌟 パーフェクト（⭐⭐⭐）**: 全拍正解！
    - **😊 グッド（⭐⭐）**: 半数以上の拍が正解！
    - **💪 がんばろう（⭐）**: 正解が半数未満。
    - 今回のパターン名と正解の強弱並び（例：「ドン！(f) → トッ(p) → トッ(p)」）を表示する。
    - 星2つ以上で「つぎへ！ ➡️」ボタンが表示され次のレベルへ進める。星1つの場合は「🔄 もういちど」でリトライ可能。

### 2.2. 太鼓パッドの定義（強弱3段階）

| ID | 記号 | 名称 | 擬音 | 役割 | カラー | 動物アイコン | 登場レベル |
|:---:|:---:|---|---|---|---|---|---|
| `'p'` | *p* (ピアノ) | よわい | **トッ** | 弱拍・小さい音 | みずいろ (`#38bdf8`) | 🐭 (`03_blue.png`) | Lv.1〜50 |
| `'mf'` | *mf* (メゾフォルテ) | ふつう | **ポン** | 中強拍・中くらいの音 | きいろ (`#fbbf24`) | 🐰 (`02_yellow.png`) | Lv.21〜50 |
| `'f'` | *f* (フォルテ) | つよい | **ドン！** | 強拍・大きい音 | あか (`#ef4444`) | 🦁 (`01_red.png`) | Lv.1〜50 |

### 2.3. 全50レベルの難易度進行と毎回問題が変化する仕組み
*   **Lv.1〜15（かんたん / 2ボタン `p`・`f` / 2〜4拍）**:
    - Lv.1〜5: 2〜3拍の強弱対比（「ドン・トッ」「トッ・ドン」「ドン・トッ・トッ」）。全拍光ガイドあり（`all`）。
    - Lv.6〜10: 2拍子マーチ（「ドン・トッ・ドン・トッ」）や3拍子ワルツ（「ドン・トッ・トッ」）。全拍光ガイドあり（`all`）。
    - Lv.11〜15: 4拍子やシンコペーション入門（「ドン・トッ・トッ・ドン」等）。前半光ガイド（`partial`）。
*   **Lv.16〜30（ふつう / 3ボタン解禁 `p`・`mf`・`f` / 4〜6拍）**:
    - Lv.16〜20: 2段階強弱での5〜6拍パターン（2拍子・3拍子の2小節連続）。最初の1音のみ光る（`first_only`）。
    - Lv.21〜25: 「中くらいの太鼓（`mf` ポン）」が加わる3ボタン解禁！クレッシェンド（`p → mf → f`）・デクレッシェンド（`f → mf → p`）や4拍子（`f → p → mf → p`）。最初の1音のみ光る（`first_only`）。
    - Lv.26〜30: 光ガイドなし（`none`）での5〜6拍クレッシェンド／デクレッシェンド・拍子パターン。
*   **Lv.31〜50（むずかしい / 光ガイドなし・微細ダイナミクス / 6〜8拍）**:
    - Lv.31〜40: 6〜7拍の複合拍子（5拍子・6拍子）、山型ダイナミクス（`p → mf → f → mf → p`）、スフォルツァンド的アクセント移動。
    - Lv.41〜50: 7〜8拍の高速・長尺ダイナミクス記憶、強弱の音量差がやや繊細になり（`contrastScale` 変化）、耳の集中力を鍛える最高難度。
*   **毎回問題が変化する仕組み**:
    - 各レベルに5種類以上の強弱パターン候補（`patterns`）を収録し、直前に出題されたパターン（`lastPatternKey`）を除外してランダム選出。
    - さらに動的バリエーション生成関数 `createDynamicsVariation(basePattern, padCount)` により、強弱反転・アクセント移動・末尾変化を動的に生成可能とし、暗記や決め打ちを防止する。

## 3. 判定・スコアリング
*   正解拍数 × 100点
*   パーフェクトボーナス（全拍正解時）：+100点
*   レベルボーナス：レベル番号 × 10点
*   星判定：全拍正解＝⭐⭐⭐、半数以上正解＝⭐⭐、半数未満＝⭐
